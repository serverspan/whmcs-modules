# Changelog

## 1.0.0-beta.1 - 2026-09-04

- Initial beta release.
- OAuth2 client-credentials authentication with encrypted token caching.
- WHMCS order-to-recipient mapping with editable courier address fields.
- Saved Colete-Online sender addresses.
- Live multi-courier price comparison.
- Shipment/AWB creation with direct service selection.
- Multi-package, COD/repayment, insurance, declared value, Saturday/open-at-delivery and scheduled-pickup options.
- Admin-protected AWB download bridge.
- Shipment history storage and explicit status refresh.
- Duplicate-shipment guard for WHMCS orders.
- Staging/production environment switch and sanitized API debug metadata.
