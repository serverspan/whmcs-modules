# Changelog

All notable changes to ServerSpan Support PIN are documented here.

## Unreleased

- Documentation and repository metadata normalized to the current ServerSpan WHMCS modules standard.
- Client-area CSRF handling hardened during the initial repository integration.

## 1.0.0 - 2026-09-04

- Initial open-source ServerSpan release.
- Client PIN generation and regeneration.
- Configurable expiry and one-time-use behavior.
- Administrator verification page and dashboard widget.
- Optional staff profile-access restrictions with temporary grants.
- Per-admin failed-attempt rate limiting and audit logging.
- Daily cleanup of expired state.
