# Support

## Module bugs

Use GitHub Issues for reproducible module bugs. Include the module version, WHMCS version, PHP version, relevant provider API mode (sandbox/production), and sanitized logs.

## Feature requests

Use the feature-request issue template and explain the operational use case, not only the desired UI change.

## Security

Follow [`SECURITY.md`](SECURITY.md). Do not post sensitive vulnerabilities publicly.

## Hosting and infrastructure

This repository is the development/support channel for the open-source modules. For hosting, VPS, reseller hosting, or infrastructure services, visit [ServerSpan](https://www.serverspan.com/en/).
