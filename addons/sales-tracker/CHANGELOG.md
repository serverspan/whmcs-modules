# Changelog

## 1.0.0-beta.1 - 2026-09-04

- Initial public beta.
- Sales dashboard with date, order-status and currency filtering.
- Sales-value and order-count trend graphs.
- Top products by units sold.
- Agent sales comparison and per-agent drill-down.
- Top sales agent ranking.
- Self/web vs. administrator-created order breakdown.
- Optional paid-invoice-only filter.
- Multi-currency-safe reporting: revenue is never summed across currencies.
- Read-only design with no custom database tables, hooks, cron jobs, remote telemetry or external JavaScript dependencies.
