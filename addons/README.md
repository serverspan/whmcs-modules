# Addon Modules

WHMCS addon modules, admin/client-area extensions, operational utilities, and billing automation live here.

No addon module has been published yet.

Modules added to this directory must be self-contained, document every database/schema change, provide a safe uninstall path where practical, and avoid modifying WHMCS core files.

For standalone infrastructure utilities outside WHMCS, see the [ServerSpan DevOps & sysadmin toolbox](https://www.serverspan.com/en/tools/index).
